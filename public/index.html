Data sources. NASA Physical Sciences Informatics (PSI) combustion investigations and experimental tables, psi.nasa.gov; publications from the NASA Technical Reports Server (NTRS), ntrs.nasa.gov. Every number on a page carries its PSI id, file and rows, or an NTRS reference.

SI disclosure. The Ask section uses a super intelligence (SI) model, Claude, restricted to the loaded PSI documents. Insights and rankings are computed by plain code from the PSI tables, not by a model. Parts of this dashboard were written with SI assistance.

License. Each PSI investigation record states its own license; it is shown on the investigation page. NTRS documents are linked, not copied. No partial-gravity data exists in PSI: every result here is microgravity, and nothing on this site says a condition is safe.
