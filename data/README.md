# Data

Source: NASA Physical Sciences Informatics (PSI) Data Repository, combustion science research area, 24 investigations (PSI-10 to PSI-159). Retrieved 2026-11-14 without login. Pages viewed show CC0-1.0 license with DOIs; check each investigation page before redistribution claims.

- psi_experimental_tables/: the "Experimental table" CSV published for each investigation (22 files), unmodified.
- psi_experimental_tables/_tables_summary.txt: column headers, row counts and sample rows per table.
- psi_combustion_inventory.json: per-investigation file counts, sizes and categories from the PSI file listing.

Raw imagery and video (about 13.5 TB in total) is not mirrored here.
