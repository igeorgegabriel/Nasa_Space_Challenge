# PSI combustion investigation metadata

Generated by `pipeline/fetch_psi_metadata.py` from the public PSI endpoint `https://psi.nasa.gov/geode-py/ws/repo/investigations/{id}`, the PSI file listing endpoint `.../ws/files/v2`, `data/unified/*.json` (fuel class, fuels, sample geometry, condition ranges) and the NASA NTRS public API.

Raw responses: `data/investigations/raw/{psi_id}.json` (PSI detail plus file listing summary) and `data/investigations/raw_ntrs/` (one file per NTRS query). Output: `data/investigations/investigations_meta.json`.

## Field provenance

- Verbatim from PSI: title, acronym, objectives, hypothesis, approach, research_impacts_earth_benefits, hardware, doi, license, publications (title, authors, doi), contacts, dates.
- `description` is the PSI `description` field. PSI leaves it empty for every investigation, so it stays blank. Use `objectives` and `approach`.
- `fuel_class`, `fuels`, `sample_geometry`, `test_conditions_unified` and `short_name` come from the unified conditions table, which was built from PSI experimental tables. Investigations absent from that table are blank.
- `test_conditions_text` is the PSI Approach text, verbatim.
- `diagnostics_measurements` are verbatim sentences from Approach, Objectives, Hypothesis and Research Impacts that name an instrument or a measurement; `diagnostics_terms` lists the instrument words matched. PSI has no structured instrument list.
- `platform` is derived from the PSI flight program and hardware strings (`platform_basis` shows which). Publication `year` is blank because PSI does not list one.
- `fire_safety_function`: keyword cues over Objectives (weight 3), Hypothesis (2) and Research Impacts (1); the highest score wins (minimum 2, so a single Research Impacts sentence alone leaves the record unassigned), ties go to suppression, detection, prevention, fundamental in that order. `fire_safety_function_basis` quotes the best supporting sentence and `fire_safety_function_candidates` lists every function with cue evidence. `unassigned` means no cue matched. This is a keyword heuristic, not a curated label: review records with several candidates before relying on the primary.
- NTRS: queries use the acronym, full title and title segments with microgravity/combustion terms. A hit is kept only when the full title, a title segment or the acronym (with a topical term) appears in the NTRS title, abstract or keywords; `match_basis` records why. Max 5 per investigation, abstract cut to 600 characters. NTRS matching was run.
